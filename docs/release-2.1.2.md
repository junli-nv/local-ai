# v2.1.2 离线客户端携带 OpenCode SDK

客户端导出会包含与 OpenCode 版本匹配的插件 SDK 和锁定的传递依赖。首次准备缺失依赖时需要联网和 npm，离线目标机可直接使用包内依赖。新会话可以在离线环境使用托管任务、Bash 自动后台化和完成通知。

OpenCode 首次加载新版 TUI 配置时会展开模型返回的思考内容。用 `/thinking` 或 `Ctrl+X` 后按 `I` 切换，之后会记住你的选择。
