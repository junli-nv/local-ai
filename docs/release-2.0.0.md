# v2.0.0：托管执行、会话迁移与批处理

本次以主版本发布：批处理 stdout 从原生 JSON 事件改为默认可读文本。旧脚本依赖事件时必须加 --format json；管理命令仍返回 JSON。历史版本标签保留。

## 使用变化

```bash
./local-ai chat run "检查当前项目并报告结果"
./local-ai chat run --prompt-file task.txt
./collect.sh | ./local-ai chat run --prompt-file -
./local-ai chat run "任务" --format json
```

文件内容作为提示词，不隐式执行；管道可以把一个脚本产生的材料交给模型，再把模型文本结果交给下一个工具。输入/输出、错误和退出码边界见[批处理指南](automation.md)。

## 新能力

- 交互 Bash 长命令自动托管，主会话可继续处理插话；任务/会话支持暂停、恢复、停止、完整输出和防重放。完成时向仍运行的聊天通知，模型读取结果后汇报。
- 本机 PTY/显式输入、核验后的进程组接管；SSH、Slurm、容器有独立执行与取消适配。
- 私有历史在线快照、独立恢复、历史选择及新项目路径映射；换模型服务器继续复用本地会话，跨 BCM 可显式迁移。
- client doctor 汇总资产、历史、后台任务、近期运行与模型请求观测，不包含对话正文；默认本地只读。
- 更新器支持活动检查、显式保留会话继续更新及独立回退脚本；程序备份和私有历史备份分开。

## 升级与验收

保留 OpenCode 1.19.5、模型 API 和推理配方；不因本次更新重启 vLLM。程序更新可保留活动客户端，退出并恢复聊天后加载新插件；个人指令与私有历史保留。历史备份 ZIP 含未脱敏对话，不能作为公共发布资产。

BCM/HGX260 的真实模型验证了插话、暂停冻结、恢复同一任务、停止确认、一次执行、自动完成汇报、同 session 恢复和新项目读取；真实 CPU SSH/Docker/Slurm 控制及文本/JSON/文件/stdin 批处理通过。原生模拟测试还覆盖 API/TUI 时序、复合 Bash 权限拒绝与允许。详细范围见[验证记录](validation.md)，不代表性能 SLA、断外网或新 GPU 配方验收。

仍有限制：其他同步工具可能阻塞；按命令的 Bash 权限保留原生同步解析；无跨聊天守护通知、远端 PTY或机器重启自动重放；接管进程不重新连接输出且自然退出码未知。KV offloading、tar 解包提速仍为低优先级。
