# Experimental RTX 6000D TP8 profile

v1.3.2 includes this profile; no temporary branch is required. First follow [README](../../README.en.md) to extract that tagged source into an empty program directory. The examples run in /raid/local-ai on GPU001 equipped with eight RTX 6000D GPUs. See [software and CDI prerequisites](prerequisites.md).

Status: experimental-hardware-validated-api-smoke. Limited hardware smoke tests passed; this remains experimental.

Requires AMD64, eight RTX 6000D GPUs with at least 85000 MiB each, and 256 GiB available host RAM. TP8, CPU Engram, 32K context, one sequence, FP8 KV/indexer, block 64, eager, text only; no DSpark/CUDA graphs.

The candidate nightly is pinned by digest. Before deployment verify vLLM fix 7ecc83a9877552a5f4be31c133ab8502dd40f50e and FlashInfer SM120 runtime page sizes (upstream at least 0.7.1rc5). Pinned image dependencies and all recipe CLI flags were checked; eight-GPU CUDA/NCCL checks passed. Model loading and limited inference smoke tests passed.

Existing models, profiles and defaults are unchanged. install saves default_profile for its installation directory; use a separate program directory to preserve an existing installation default. Check CDI and idle GPUs/port; verify dependencies before install/start:
```bash
./local-ai server plan --profile rtx6000d-tp8 --gpus 0,1,2,3,4,5,6,7 --name a --port 18000 --inventory tests/fixtures/rtx6000d-tp8.json
./local-ai install --role server --profile rtx6000d-tp8
./local-ai server start --host 0.0.0.0 --profile rtx6000d-tp8 --gpus 0,1,2,3,4,5,6,7 --name a --port 18000 --wait-timeout 1200
./local-ai server status --name a
```

Default binding: 127.0.0.1. For BCM access explicitly set --host 0.0.0.0 and use the actual hostname in the endpoint. Model: DeepSeek-V4.1-Flash-SM120; client context 32768, configured output limit 8192, text only. The sanitized fixture plan allocates no GPUs.

Pending: full 32K boundary, concurrency, sustained stability and performance tuning. B300 validation does not apply. [中文](../rtx6000d.md)

## Reproduce eight-GPU communication checks

Run in the program directory on GPU001 with GPUs and port 29501 idle. Host networking and explicit loopback rendezvous avoid an unresolvable container hostname from --standalone; this check loads no model.

```bash
rtx_image=vllm/vllm-openai@sha256:390a656b54e12144ad15ff32244c6e848408b0ee94f2c4c5a84451e7430f1aa7
docker run --rm --network host --ipc host --device nvidia.com/gpu=all --mount type=bind,src="$PWD/scripts",dst=/checks,readonly -e NCCL_SOCKET_IFNAME=lo -e GLOO_SOCKET_IFNAME=lo -e NCCL_IB_DISABLE=1 --entrypoint torchrun "$rtx_image" --nnodes=1 --node-rank=0 --nproc-per-node=8 --master-addr=127.0.0.1 --master-port=29501 --rdzv-conf timeout=60 /checks/check-rtx6000d.py
```
