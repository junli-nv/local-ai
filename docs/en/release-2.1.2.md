# v2.1.2 OpenCode SDK in offline client bundles

Client exports now include the version-matched OpenCode plugin SDK and its locked transitive dependencies. Preparing missing dependencies requires network access and npm. Offline targets can use the bundled dependencies to start managed tasks, automatically background long Bash commands, and receive completion notifications.

OpenCode expands model reasoning the first time it loads the updated TUI configuration. Use `/thinking` or press `Ctrl+X` followed by `I` to toggle it. OpenCode remembers your choice.
