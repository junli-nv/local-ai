# v2.1.4 Toasts for automatic background tasks

When OpenCode automatically backgrounds a Bash command, local-ai shows a brief completion or warning toast. These completions leave the chat transcript undisturbed. If you want a follow-up from the assistant, ask for a completion report. Task status and output remain available on demand.

After updating, exit and resume your OpenCode session to load the new notification behavior.
