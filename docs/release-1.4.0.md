# v1.4.0 发布说明

本版以客户端任务可靠性与可观察性为主，服务端配方与硬件支持范围按既有验证记录保持。

- 私有请求诊断：API 响应 usage、首段内容延迟、请求与工具耗时、上下文占用；缺失缓存明细显示未知。
- 长会话交接：保留原生压缩与 prune，为压缩摘要补充目标、约束、证据和未完成操作；新增 /handoff。
- 长任务管理：client tasks / client report，批处理期限、存活提示、进程组清理与恢复命令；不自动重放写操作。
- 真实工作流验收：client workflow 的 edit-test、diagnose、resume，在独立私有目录检查实际文件结果。
- 同时正式交付前期 main 上的 server benchmark、持久指令模板和个人规则加载。
- 原生依赖缓存按客户端身份复用，连接配置仍按会话隔离，避免每个会话重复初始化。

## 验证与边界

OpenCode 1.19.5 在本次检查时仍为 NPM 最新版本，继续使用已验收版本。
CPU 回归、原生工具往返、同会话恢复、压缩钩子与真实 DeepSeek API 三个小型工作流分别验证。
GPU 配方、复杂长上下文质量、长期并发及 benchmark 的真实 GPU 性能不因此扩大验收。
当前服务 API 未返回单请求缓存明细，新报告显示 null；全局缓存命中率不能替代单请求统计。
首段内容可能是 reasoning 或工具调用，API 耗时不拆分为网络、排队和 prefill。
摘要由模型生成，恢复前仍需核对外部状态；KV offloading 继续作为低优先级储备。

## 获取和升级

源码包含 Python 程序、observer.mjs、模板、文档和测试；不包含模型、容器镜像、客户端二进制或个人历史。
按 [README](../README.md) 安装；已有安装按[程序更新](update.md)分别更新两端。
客户端新开或恢复会话后生效；GPU 服务无需为客户端功能重启。
旧运行记录不回填。诊断与工作流用法见[命令手册](commands.md#任务诊断与工作流回归v140)。
