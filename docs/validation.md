| 配置 | 单请求 TTFT 中位数 ms | 单请求生成 token/s P50 | 四并发总吞吐 token/s |

| vLLM DSpark | 381.8 | 459.9 | 352.0 |
| SGLang 基线 | 549.2 | 166.6 | 267.8 |
| SGLang DSpark | 591.6 | 303.5 | 300.6 |
