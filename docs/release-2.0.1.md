# v2.0.1：客户端可靠性修复

本次收录 v2.0.0 之后已完成的修复，不包含储备功能。OpenCode 仍为 1.19.5。

- 安装个人规则时，私有备份后迁移精确匹配的旧模板副本，保留定制文字与代码示例。
- chat run 支持提示词前后放置选项，文本／JSON／文件／stdin 行为保持一致。
- client job recover 按已有 SSH／Slurm／容器后端身份恢复监控，不重新提交命令；已确认终态和有界连续输出缓存可在连接失败后读取，部分覆盖明确报告。
- 修正原生 controls 验收的异步时序假设，保留权限、暂停、停止和只执行一次的断言。
- 同步当前下载、更新与离线示例，记录[延期事项](development.md#后续储备2026-11-19)。

已有会话与个人配置保留；更新客户端后退出并恢复聊天以加载插件，无需重启模型服务。恢复仍要求匹配的原生 OpenCode 版本。新的恢复路径已实测 SSH；Slurm／容器恢复、严格离线和长期压力仍属后续验收，见[验证记录](validation.md)。
