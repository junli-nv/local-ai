# RTX 6000D 八卡实验配方

v1.3.2 已包含本配方，无需切换临时分支。先按 [README](../README.md) 将该标签源码解压到空的程序目录；下例在配有八张 RTX 6000D 的 GPU001 上执行，目录为 /raid/local-ai。软件前提见[版本与 CDI 检查](prerequisites.md)。

状态 experimental-hardware-validated-api-smoke：有限实机冒烟通过，仍为实验配方。

要求 AMD64、八张 RTX 6000D，每卡至少 85000 MiB、主存可用至少 256 GiB。TP8，CPU Engram，32K 上下文，单序列，FP8 KV/indexer，block 64，eager，纯文本；无 DSpark/CUDA Graph。

候选 nightly 已按摘要固定。部署前须核实包含 vLLM 修复 7ecc83a9877552a5f4be31c133ab8502dd40f50e，及 FlashInfer SM120 runtime page sizes（上游至少 0.7.1rc5）。固定镜像依赖和全部配方 CLI 参数已验证，八卡 CUDA/NCCL 基础检查通过；模型加载和有限推理冒烟已通过。

原有模型、配方、默认值保持不变。install 会保存当前安装目录的 default_profile；若要保留已有安装默认值，在独立程序目录试部署。先检查 CDI、GPU/端口空闲，核实镜像依赖后再 install/start：
```bash
./local-ai server plan --profile rtx6000d-tp8 --gpus 0,1,2,3,4,5,6,7 --name a --port 18000 --inventory tests/fixtures/rtx6000d-tp8.json
./local-ai install --role server --profile rtx6000d-tp8
./local-ai server start --host 0.0.0.0 --profile rtx6000d-tp8 --gpus 0,1,2,3,4,5,6,7 --name a --port 18000 --wait-timeout 1200
./local-ai server status --name a
```

默认监听 127.0.0.1；BCM 访问显式 --host 0.0.0.0，endpoint 使用实际主机名。模型名 DeepSeek-V4.1-Flash-SM120：客户端上下文 32768、输出配置上限 8192，仅文本。plan 清单脱敏且不占用 GPU。

待继续验收：完整 32K 边界、并发、长期稳定性及性能优化。不要继承 B300 验收结论。[English](en/rtx6000d.md)

## 基础环境验证：2026-11-08

固定镜像 cf5cea2d 包含 SM120 修复，实际 vLLM 0.33.0rc1.dev1030、FlashInfer 0.7.3、CUDA 13.0。八卡 BF16 与 NCCL all-reduce 通过，GPU P2P 能力矩阵为全互通。此处是能力查询，不是 P2P 带宽验收。权重内容校验、离线安装和有限推理冒烟已通过。

## 复现八卡通信检查

在 GPU001 的程序目录运行，确认 GPU 和 29501 端口空闲。使用 host 网络和显式回环会合地址，避免 --standalone 选到无法解析的容器主机名；此检查不加载模型。

```bash
rtx_image=vllm/vllm-openai@sha256:390a656b54e12144ad15ff32244c6e848408b0ee94f2c4c5a84451e7430f1aa7
docker run --rm --network host --ipc host --device nvidia.com/gpu=all --mount type=bind,src="$PWD/scripts",dst=/checks,readonly -e NCCL_SOCKET_IFNAME=lo -e GLOO_SOCKET_IFNAME=lo -e NCCL_IB_DISABLE=1 --entrypoint torchrun "$rtx_image" --nnodes=1 --node-rank=0 --nproc-per-node=8 --master-addr=127.0.0.1 --master-port=29501 --rdzv-conf timeout=60 /checks/check-rtx6000d.py
```

## 实机冒烟结果：2026-11-08

- 48 个权重分片全部通过固定 revision 的 SHA256 校验，90 个文件内容验证完成；共享副本只读。
- 独立目录离线安装通过；八卡 TP8 冷启动约 177 秒，健康检查 HTTP 200。

- 仍未验收完整 32768-token 边界、并发、长期稳定性、视觉输入、CUDA Graph 和 DSpark；保持 eager、单序列、文本基线。

## 在 BCM 连接

按 [README](../README.md#2-在-bcm-安装并使用) 安装或更新 BCM 客户端到 v1.3.2。在 BCM 的 /raid/local-ai 执行，将 GPU001 换成实际服务端主机名；工具仍在 BCM 当前用户下运行。客户端必须选择独立服务模型，不能沿用 B300 的默认模型名。

```bash
./local-ai chat --endpoint http://GPU001:18000/v1 --model DeepSeek-V4.1-Flash-SM120 --check
./local-ai chat --endpoint http://GPU001:18000/v1 --model DeepSeek-V4.1-Flash-SM120 --project /home/alice/project
```
